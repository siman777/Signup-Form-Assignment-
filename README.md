# 🚀 Signup Form

A clean and minimalist signup form built using **HTML5 and CSS3**,
featuring a modern dark-themed interface, intuitive form elements,
and native HTML validation.

## ✨ Features

- Modern and minimalist dark-themed user interface
- Full name and email input fields
- Password and confirm password fields
- Date of birth selection
- Profession selection (Student or Employee)
- Terms and conditions acceptance
- Native HTML5 form validation
- Custom browser tab favicon
- Flexible form layout
- Clean and organized source code
- Lightweight implementation without external dependencies

## ⚙️ Getting Started

Follow these simple steps to run the project locally:

1. Clone or download this repository.
2. Navigate to the project directory.
3. Open `index.html` in your preferred web browser.

No external libraries, frameworks, or additional dependencies
are required.
